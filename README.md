# Riku Nagano

### Computer Vision · Applied AI · Robotics

I am an engineer based in Japan with a master's degree in engineering. I build image recognition and object detection systems, connect perception to robotic control, and turn AI models into usable software.

My experience spans **Python, PyTorch, OpenCV, YOLOv8, agricultural image analysis, OCR, and MPPI control**. I am particularly interested in agricultural robotics, where perception has to work reliably beyond a benchmark dataset.

## Selected experience

**Vision-based drone control**  
Research combining YOLOv8 object detection with Model Predictive Path Integral (MPPI) control for drone obstacle avoidance. My work includes Python implementation and integration of camera observations with a control loop. This is research and prototype work, rather than a claim of production autonomy.

**Agricultural AI and IoT**  
Development of AI systems using satellite data to estimate crops and farmland conditions, alongside agricultural applications, data collection, and hardware-related prototyping.

**OCR and computer vision applications**  
Development of text detection, recognition, and extraction models; task-specific evaluation and error analysis; and delivery of web applications that use AI models.

## How I approach engineering

- Define the practical task and evaluation criteria before choosing a model.
- Inspect failure cases and improve the data, model, and surrounding software together.
- Treat latency, perception errors, and integration constraints as part of the system.
- Explain results and limitations clearly so the next engineering decision is useful.

Much of my project code is maintained in private repositories. I can discuss my own contributions and share appropriate, non-confidential material during technical conversations.
